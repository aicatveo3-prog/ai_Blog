# ByteDance Seedream 5.0 Pro — 교차검증 노트

> 프롬프트 K 기반. 세 소스(정리본·자세히·반응)를 훑어 모순·정합성·구멍을 정리.

---

## 1. 핵심 모순/아이러니 — 앵글 후보

1. **"디자인을 이해한다"는 주장 vs 독립 검증 부재** — ByteDance가 레이아웃·색상·타이포그래피까지 이해한다고 자체 평가했지만, 독립 벤치마크 비교는 없다. TechCrunch가 "GPT-4V·Gemini 경쟁 수준"이라 했으나 이것도 정밀 비교는 아닌 기사 수준. (정리본·자세히)
2. **아시아 언어 텍스트 생성 강조 vs 공개 샘플은 영어·중국어 위주** — 한글·일본어 처리를 내세우지만 실제 시연은 확인 못 함. (자세히)
3. **AI 감정 대화 서비스 폐쇄(Doubao) vs 새 AI 창작 도구 출시** — ByteDance가 한쪽에서 규제로 AI 서비스를 닫으면서 다른 쪽에서 새 AI 도구를 출시. 단, 다른 팀·다른 용도라 과도한 연결은 삼간다. (반응 - Bloomberg 링크)

## 2. 사실 정합성 체크

- 정리본과 자세히 사이 수치·날짜 불일치는 없음. 두 소스 모두 ByteDance 공식 블로그를 기반으로 작성.
- 첫 등장일: 2026-07-08 (정리본·자세히 일치, TechCrunch 기사는 7/14 — 후속 보도)

## 3. 주장 vs 교차확인된 사실

| 주장 (ByteDance 발표) | 교차확인 |
|---|---|
| 디자인 원칙을 이해한다 | ByteDance 자체 평가만. 독립 벤치마크 없음 |
| GPT-4V·Gemini 경쟁 수준 | TechCrunch 기사 평가 (독립 벤치마크는 아님) |
| 한글·중국어·일본어 텍스트 생성 | ByteDance 주장만. 공개 샘플로 독립 검증 안 됨 |
| 실시간 협업 기능 내장 | ByteDance 주장만 |
| API·웹 플랫폼 제공 예정 | ByteDance 주장만 |
| 중국 시장 우선 출시 | ByteDance 발표 (자세히) |

## 4. 확인 못 한 구멍

- 가격/API 비용 정보: 없음
- 글로벌 출시 시점: "검토 중"만
- 한글 텍스트 생성 실제 품질: 독립 테스트 없음
- 반응 소스가 매우 빈약 — 한국 개발자 커뮤니티 반응(Brunch·Rubicontech) 링크만 있고 구체적 인용이 없음
- 경쟁사(OpenAI·Google) 대응 반응: 없음
