# 조사 노트: n8n, MCP 허브가 되다

- 소스 티어: 1차(n8n 공식 Docs/Changelog) + 2차(Releasebot, Infralovers, Generect)
- 조사 날짜: 2026-07-04
- 글 유형: A 속보 브리핑 / 렌즈 ①②
- 👉 출처는 맨 아래 "출처 링크"

## A. 확인된 팩트
- F1. **n8n 2.0은 AI 기능 릴리즈가 아니다.** 보안·신뢰성·성능 릴리즈다 — Code 노드 기본 샌드박스 실행, Publish/Save 워크플로 패러다임. [출처 1,2]
- F2. **2026-05-19**: 노드 패널에서 MCP 서버를 골라 에이전트에 붙이기 — MCP Client 노드·자격증명 수동 설정 불필요. 초기 커버리지: **Apify, Linear, monday.com, Notion, PostHog**. [출처 3]
- F3. **양방향 MCP**: MCP 서버를 에이전트 도구로 소비 + 자기 워크플로를 MCP 서버로 노출(외부 AI가 호출). [출처 3,4]
- F4. **2026-04**: 인스턴스 레벨 MCP 서버 — Claude Desktop·ChatGPT·Cursor 등이 n8n 안에서 워크플로 build/test/publish. Cloud·Enterprise·Community(**v2.18.4+**). [출처 2,3]

## B. 주장·해석
- "n8n이 에이전틱 MCP 허브가 됐다"는 해석 [출처 4]
