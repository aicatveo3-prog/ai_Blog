# 교차검증 — Moonshot Kimi K3 (2026-07-18)

## 1. 핵심 모순/아이러니 — 앵글 후보

- **1위**: 미국이 3년간 중국에 GPU·칩 수출을 제한했는데, 중국 모델(Kimi K3)이 오히려 프론티어 수준에 도달함 → "수출 통제가 못 막은 것" (자세히/반응). 가장 극적인 어긋남. 독자가 가장 놀랄 포인트.
- **2위**: Moonshot이 "전 세계 4위"라고 자체 벤치마크로 주장하는데, 독립 검증은 아직 없음 (정리본/자세히). Sam Altman도 처음엔 "풍자인 줄 알았다"고 함 → 회사 주장 vs 외부 의심.
- **3위**: "오픈 가중치"라고 하면서 Modified MIT 라이선스 — 완전한 오픈소스와는 다름 (정리본). 전체 가중치 공개도 7/27 예정이라 아직 안 나옴.

## 2. 사실 정합성 체크

- TechCrunch 제목 "close the gap with Opus 4.8" vs Moonshot 자체 벤치마크 "Opus 4.8을 상회" → **표현 수위가 다름**. TechCrunch는 따라잡는 수준, Moonshot은 앞섰다고 주장. 글에서 Moonshot의 주장임을 명시 필요.
- 전체 가중치 공개 예정일: 2026-07-27 (Axios) — 다른 소스와 일관.
- 파라미터 수: 2.8T — 모든 소스 일관.
- 가격 입력 $3/M, 출력 $15/M — Codersera 소스, 일관.

## 4. 확인 못 한 구멍

- 독립 벤치마크(Chatbot Arena 등) 결과 아직 없음
- 한국어 성능 테스트 결과 없음 (Gadget Otaku에서 한국어 지원 여부가 핵심이라 언급하지만 테스트 결과는 미공개)
- Anthropic의 공식 반응 없음 (CNBC에서 "공식 성명 없음" 확인)
- 실제 활성 파라미터 수 미명시 (전체 2.8T 중 16/896 전문가 활성화)

## 5. 떡밥 후보

- 7월 27일 전체 가중치 공개 → "진짜 실력은 개발자들이 직접 돌려봐야 안다"
- Sam Altman의 "풍자인 줄 알았다" → 뒤에서 경쟁 기업 반응 섹션에서 회수
