# 프롬프트 D — P2 아웃라인 생성 (프롬프트 체인 2단)

> 용도: 팩트 목록 + 관점 한 문장으로 아웃라인 2안 생성.
> **★ 이 게이트가 전체 체인에서 가장 중요하다 ★** — 구조가 틀린 글은 문장을 아무리 고쳐도 못 살린다.
> **사람 승인 없이는 P3로 넘어가지 않는다.**

```text
아래만을 재료로 블로그 글 아웃라인을 서로 다른 구조로 2안 만들어라.
- 글 유형: {A/B/C/D 중 하나 + 해당 템플릿 구조}
- 이 글의 관점(한 문장): {확정된 관점}
- 팩트 목록: {P1 출력}

규칙:
- 모든 섹션에 (사용할 팩트 번호)를 표기. 팩트 없는 주장 섹션은 "저자 경험 필요"로 표시.
- 각 안마다 도입부 훅 후보 2개(첫 두 문장 초안)를 포함.
- 두 안은 구조적으로 달라야 한다 (예: 1안 시간순, 2안 주장 우선).
- 분량 배분(자수)을 섹션별로 표기.
```

→ 사람이 하나를 고르고, 수정 지시를 한 뒤 **승인**한다.
