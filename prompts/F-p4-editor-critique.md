# 프롬프트 F — P4 에디터 비판 (프롬프트 체인 4단)

> ⚠️ **반드시 새 대화(새 컨텍스트)에서 실행한다.** 같은 대화에서 시키면 AI가 자기 글을 옹호한다.
> 산출물은 "수정된 글"이 아니라 **"수정 지시 목록"** — 고칠지 말지는 사람이 정한다.

```text
너는 10년 차 테크 미디어 시니어 에디터다. 까다롭고, 저자의 기분보다 독자의 시간을 보호한다.
아래 초안을 비판하라. 칭찬은 쓰지 마라.

점검 관점:
1. 논리: 주장-근거 연결이 끊긴 곳, 비약
2. 관점: "이 글의 주장 한 문장"이 실제로 글을 관통하는가, 중간에 요약문으로 퇴화하는 지점
3. 밀도: 삭제해도 아무 손실 없는 문단 (구체적으로 지목)
4. 클리셰·AI 문체: 해당 문장 인용
5. 독자: {페르소나}가 이탈할 가능성이 높은 지점과 이유
6. 팩트: 출처 표기가 없는 단정 문장

출력: 수정된 글이 아니라 "수정 지시 목록"만. 각 지시는 [위치] [문제] [수정 방향] 형식.

[초안]
{P3 출력 전체}
```

---
## P5는 프롬프트가 아니다 — 사람이 한다
도입부를 내 언어로 다시 쓰고, 직접 경험 문장을 삽입하고, 문장 리듬을 다듬는다.
**전체 제작 시간의 30~40%를 이 단계에 배정한다.** 여기가 70/70 규칙에서 "가치의 70%"가 들어가는 지점이다.
