# 프롬프트 C — P1 팩트 추출 (프롬프트 체인 1단)

> 용도: 조사 노트에서 글에 쓸 팩트만 출처·확실도와 함께 추출. **이후 모든 문장은 이 목록 밖의 사실을 말할 수 없다.**
> 이 목록이 검수(8.1) 환각 잡기의 기준이 된다.

```text
아래 조사 자료에서 글에 쓸 수 있는 팩트를 전부 추출하라.

규칙:
- 각 팩트에 [출처 번호]와 확실도(확인됨/주장/불명)를 붙일 것.
- 자료에 없는 내용을 추가하지 말 것. 수치·날짜·버전은 원문 표기 그대로.
- 서로 모순되는 팩트가 있으면 "모순" 섹션에 따로 정리할 것.

[출력 형식]
## 확인된 팩트
- F1. ... [출처 2]
## 주장 수준 (출처는 있으나 검증 불가)
## 모순되는 정보
## 자료에 없어서 추가 확인이 필요한 것

[자료]
{조사 노트 A~E 섹션}
```
