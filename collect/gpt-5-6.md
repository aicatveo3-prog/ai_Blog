# OpenAI GPT-5.6: "분할 전략"으로 모든 개발자를 만족시키다

## 무엇이 일어났나?

2026년 7월 9일, [OpenAI가 공식적으로 GPT-5.6을 출시](https://openai.com/blog/gpt-5-6/)했습니다. 흥미로운 점은 **한 가지 모델을 출시한 게 아니라, 성능과 가격대가 다른 3가지 버전을 동시에 출시**했다는 것입니다.

이는 6월 26일 [정부 승인 후 제한적으로 미리본](https://openai.com/blog/) 것을 정식 공개한 것입니다. 왜 정부 승인이 필요했을까요? 초강력 AI의 안전성과 규제를 미리 검토하기 위해서입니다.

## 왜 "분할 전략"인가?

### 1. Sol - 최고 성능의 선택

[GPT-5.6 Sol](https://openai.com/gpt-5-6/)은:
- **입력:** $5 / 백만 토큰
- **출력:** $30 / 백만 토큰

"비싼 대신 가장 똑똑하다"는 의미입니다. 의료 진단, 법률 분석, 과학 논문 작성 같은 **고도의 전문적 작업**에 최적화되었습니다.

### 2. Terra - 가성비의 선택

[GPT-5.6 Terra](https://openai.com/gpt-5-6/)는:
- **입력:** $2.50 / 백만 토큰 (Sol의 50%)
- **출력:** $15 / 백만 토큰 (Sol의 50%)

"괜찮은 성능을 합리적 가격에"라는 목표입니다. **대부분의 기업 업무**(고객 지원, 콘텐츠 생성, 데이터 분석)에 충분합니다.

### 3. Luna - 빠르고 저렴한 선택

[GPT-5.6 Luna](https://openai.com/gpt-5-6/)는:
- **입력:** $1 / 백만 토큰
- **출력:** $6 / 백만 토큰

"빠르고 싸다" = 개발자 테스트, 간단한 질의응답, 실시간 챗봇에 최적화. 스타트업이나 프로토타입 개발에 이상적입니다.

## 신제품: ChatGPT Work 에이전트

동시에 [ChatGPT Work 에이전트](https://openai.com/chatgpt-work/)도 출시되었습니다.

이게 뭘까요?
- **자동화 AI**: 사람의 개입 없이 특정 작업을 자동으로 수행
- **통합 기능**: Slack, Google Workspace, Salesforce 등 주요 업무 도구와 연동
- **의사결정 능력**: 단순히 질문에 답하는 게 아니라, "이메일 수신 → 우선순위 판단 → 담당자에게 배정"과 같은 워크플로우 자동 실행

예를 들어, HR 부서는 ChatGPT Work로 **채용 공고 검토 → 이력서 평가 → 면접 일정 안내**를 모두 자동화할 수 있습니다.

## 시장에 미치는 영향

### 개발자 입장
"다양한 선택지가 생겼다!" → 프로젝트 예산에 맞춰 모델 선택 가능

### 기업 입장
"OpenAI가 장기적으로 시장을 독점하려 한다" → Sol로 중요한 작업, Luna로 대량 작업 처리 가능

### 경쟁사(Google, Anthropic) 입장
"분할 전략은 위험하다" → OpenAI가 시장 대부분을 차지할 수 있음

## 용어 사전

| 용어 | 설명 |
|------|------|
| **API 가격** | 개발자가 모델을 사용할 때마다 지불하는 비용 |
| **입력/출력 가격 분리** | 모델에 "질문 입력"할 때와 "답변 받을" 때 다른 가격 |
| **백만 토큰** | 약 75만 단어, 책 3권 분량 |
| **에이전트** | 사람의 지시를 받아 자동으로 여러 단계의 작업을 수행하는 AI |
| **워크플로우 자동화** | 반복적인 업무 절차를 자동으로 처리 |

## 왜 정부 승인이 필요했나?

초강력 AI가 경제와 사회에 미치는 영향이 커졌기 때문입니다:
- 대량 실업 우려
- 데이터 프라이버시 문제
- AI의 편향성 및 오류 가능성

따라서 미국 정부는 **공개 전에 안전성과 사회적 영향을 사전 검토**하도록 요청했습니다.

## 평가 및 한계

**긍정적:**
- 모든 개발자와 기업이 사용할 수 있는 선택지 제공
- 가격 경쟁력(Terra, Luna)으로 진입장벽 낮춤
- Work 에이전트로 엔터프라이즈 자동화 시장 개척

**우려점:**
- OpenAI의 시장 독점 심화
- 경쟁사(Google, Anthropic, 중국 Moonshot)의 추격이 심화된 상황에서 분할 전략이 얼마나 오래 유효할지 불명확
