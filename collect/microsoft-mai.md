## 한마디로 요약

Microsoft가 2026년 6월 2일, **자체 개발한 AI 모델 7종(MAI 시리즈)**을 한꺼번에 공개했습니다. 지금까지 Microsoft는 OpenAI(ChatGPT를 만든 회사)의 AI를 '빌려 쓰는' 입장이었는데, 이제 **"우리 것도 있다"**고 선언한 겁니다. 이것이 왜 큰 뉴스인지, 하나씩 풀어보겠습니다.

---

## 왜 이게 뉴스가 되나? — 배경 이해하기

Microsoft와 OpenAI의 관계를 먼저 알아야 합니다.

**그동안의 구도:**
- Microsoft는 OpenAI에 **수조 원을 투자**했습니다.
- 그 대가로 OpenAI의 AI 기술을 가져다가 자기 제품(Windows 코파일럿, Office, Azure 등)에 넣어 팔았습니다.
- 쉽게 말하면, **자동차 회사인데 엔진은 다른 곳에서 사 오는** 상황이었습니다.

**문제점:**
- 핵심 기술이 **남의 것**이니, OpenAI가 마음을 바꾸거나 가격을 올리면 곤란합니다.
- AI 시대에 **엔진(모델)을 직접 만들 줄 모르는 회사**라는 인식도 부담이었습니다.

**그래서:** Microsoft가 자기 엔진을 직접 개발하기 시작한 겁니다. 그 결과물이 바로 이번 **MAI 시리즈**입니다.

---

## 공개된 7개 모델 — 한눈에 보기

**MAI**는 "Microsoft AI"의 약자입니다. 용도별로 7개가 나왔습니다.

| 모델 이름 | 하는 일 | 쉽게 말하면 |
|---|---|---|
| **MAI-Thinking-1** | 복잡한 문제를 '생각해서' 풀기 | AI계의 '수학 천재' |
| **MAI-Code-1-Flash** | 코드 작성 도우미 | AI계의 '빠른 프로그래머' |
| **MAI-Image-2.5** | 고품질 이미지 생성 | AI계의 '화가' |
| **MAI-Image-2.5-Flash** | 빠른 이미지 생성 | '화가'의 속성 버전 |
| **MAI-Transcribe-1.5** | 음성을 텍스트로 변환 | AI계의 '속기사' |
| **MAI-Voice-2** | 사람 같은 음성 생성 | AI계의 '성우' |
| **MAI-Voice-2-Flash** | 빠른 음성 생성 | '성우'의 속성 버전 |

이 중에서 특히 주목할 두 모델을 자세히 살펴보겠습니다.

## 주목 ① — MAI-Thinking-1: "생각하는 AI"

### 이게 뭔가요?

보통 AI는 질문을 받으면 바로 답을 내놓습니다. 그런데 **'생각하는 모델(reasoning model)'**은 다릅니다. 답을 내기 전에 **스스로 단계별로 추론하는 과정을 거칩니다.** 어려운 수학 문제를 풀 때 바로 답을 찍지 않고, 풀이 과정을 하나씩 밟아가는 것처럼요.

### 얼마나 큰가요?

- **파라미터 1조(1,000,000,000,000)개.** 파라미터란 AI 두뇌 속의 '연결 고리' 같은 것으로, 많을수록 대체로 더 복잡한 문제를 다룰 수 있습니다.
- 하지만 여기서 재밌는 점이 있습니다. 1조 개가 전부 항상 켜져 있는 게 아닙니다. **한 번에 실제로 작동하는 건 350억(35B)개뿐입니다.**

### 왜 일부만 쓰나요? — MoE 구조

이걸 **MoE(Mixture of Experts, 전문가 혼합)** 방식이라고 합니다.

비유하면 이렇습니다: 병원에 **100명의 전문의**가 있다고 상상해 보세요. 환자가 오면 100명이 다 달려드는 게 아니라, **증상에 맞는 전문의 3~4명만 진료**합니다. 나머지는 대기실에서 쉬고 있죠. 이렇게 하면 100명분의 전문성은 갖추되, 한 환자에 드는 비용은 3~4명분으로 줄어듭니다.

MAI-Thinking-1도 같은 원리입니다. 1조 개의 방대한 지식을 갖고 있지만, 질문에 필요한 350억 개만 활성화해서 답합니다. **성능은 크고, 비용은 작게.**

### 성적은?

- 수학 경시대회 문제(AIME)에서 **97% 정답률.**
- 사람들이 직접 블라인드 테스트를 했을 때(어느 AI의 답인지 모르는 상태로 비교), **Claude Sonnet 4.6보다 MAI-Thinking-1의 답을 더 선호**했다고 발표.

### 하나 더 — "베끼지 않았다"

Microsoft는 한 가지를 강하게 강조했습니다. **다른 AI의 답을 베껴 학습(distillation)하지 않았다**는 점입니다.

distillation이란 '증류'라는 뜻인데, AI 세계에서는 **잘하는 AI의 답안지를 모아서 다른 AI를 가르치는 것**을 말합니다. 시험에 비유하면, 모범생의 답을 베껴서 공부하는 것이죠. 효율적이지만, "진짜 실력이냐"는 논란이 있습니다.

Microsoft는 **출처가 깨끗하고 추적 가능한 데이터로만 훈련**했다고 밝혔습니다.

## 주목 ② — MAI-Code-1-Flash: "빠르고 싼 코딩 조수"

### 이게 뭔가요?

프로그래밍(코딩)을 도와주는 AI입니다. 개발자가 "이런 기능을 만들어줘"라고 하면 코드를 써 주고, 기존 코드의 버그도 찾아줍니다.

### 뭐가 특별한가요?

**'적응형 사고(Adaptive Thinking)'** 기능이 있습니다.

- 쉬운 요청("변수 이름 바꿔줘") → 거의 생각 없이 **즉시 답변**
- 어려운 요청("이 시스템의 성능 병목을 찾아서 개선해줘") → **더 오래 생각한 뒤** 깊은 답변

사람도 간단한 질문엔 바로 대답하고, 복잡한 질문엔 곰곰이 생각하잖아요. 이 AI도 그렇게 합니다. 덕분에 **쉬운 작업에 불필요한 시간과 비용을 쓰지 않습니다.**

### 성적은?

- 비슷한 급의 **Claude Haiku 4.5를 코딩 시험 4개에서 전부 앞섰습니다.**
- 같은 문제를 푸는 데 **최대 60% 적은 토큰(계산량)**을 사용. 즉, **더 싸고 더 빠릅니다.**

### 가격과 사용처

- **입력 100만 토큰당 $0.75, 출력 $4.50** (토큰은 AI가 글을 세는 단위로, 대략 단어 조각 하나입니다)
- **GitHub Copilot(VS Code)**에 이미 투입되기 시작했습니다.

## 이게 우리한테 어떤 의미인가?

**1. AI 시장의 판도가 바뀌기 시작합니다.**
지금까지 AI의 '두뇌(모델)'를 만드는 건 OpenAI, Google, Anthropic 같은 전문 회사의 영역이었습니다. 그런데 **IT 플랫폼 공룡 Microsoft까지 직접 만들기 시작**하면, 경쟁이 훨씬 치열해집니다.

**2. 사용자 입장에선 좋은 일입니다.**
선택지가 늘어나고, 경쟁이 붙으면 **가격은 내려가고 품질은 올라갑니다.** 지금도 이미 AI API 가격은 매년 급격히 떨어지고 있는데, 이 추세가 더 빨라질 수 있습니다.

**3. "빌려 쓰는 시대"에서 "직접 만드는 시대"로.**
Microsoft의 움직임은 "아무리 큰 회사라도 핵심 AI를 남에게 의존하면 위험하다"는 인식을 보여줍니다. 앞으로 다른 대기업들도 자체 모델 개발에 뛰어들 가능성이 높습니다.

## 용어 사전

| 용어 | 뜻 |
|---|---|
| **모델(model)** | AI의 '두뇌' 하나하나를 부르는 말. ChatGPT, Claude, MAI 각각이 모델입니다. |
| **파라미터(parameter)** | 모델 내부의 연결 고리 수. 많을수록 대체로 성능이 높지만 무겁습니다. |
| **MoE(Mixture of Experts)** | 큰 모델을 여러 '전문가'로 나누고, 질문마다 관련 전문가만 활성화하는 구조. |
| **토큰(token)** | AI가 글을 세는 단위. 대략 단어 한 조각. 가격과 속도가 토큰 수로 계산됩니다. |
| **distillation(증류)** | 잘하는 AI의 답을 모아 다른 AI를 가르치는 학습법. |
| **벤치마크(benchmark)** | AI끼리 같은 시험을 치르게 해 성적을 비교하는 것. AIME(수학), SWE-Bench(코딩) 등. |
| **GitHub Copilot** | Microsoft가 만든 코딩 도우미 서비스. VS Code 등 개발 도구에서 사용. |
