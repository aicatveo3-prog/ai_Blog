# 내 GPU로 뭘 돌릴 수 있나 — 로컬 LLM 2026, VRAM부터 보자

> **유형** · C 가이드형  **상태** · 검수중(P5 사람 편집 대기)
> **관점** · "GPT 살 돈·프라이버시 걱정?"의 답은 모델명이 아니라 **내 VRAM 기준으로 뭘 돌릴 수 있나**다.

**한 줄 요약** — 로컬 LLM은 2026년에 확 쉬워졌다. 핵심은 딱 하나, **내 그래픽카드 VRAM**이다. 그 숫자만 알면 뭘 돌릴 수 있는지 정해진다.

---

## 먼저: VRAM 기준표 (이게 전부다)

| 모델 크기 | 필요 VRAM(Q4) | 예시 GPU |
|---|---|---|
| 7B | 약 4~5GB | RTX 4060 (8GB) |
| 14B | 약 8~10GB | RTX 4070 급 |
| 30B | 약 16~20GB | RTX 4090 / 다중 GPU |

*[F5]* — 모델명보다 이 표가 먼저다. 내 카드 VRAM을 확인하고 거기서 시작한다.

## 2026년, 뭘 고를까

- **소비자 GPU 1장이면**: **Gemma 3 27B**(약 16GB) 또는 **Phi-4 14B**(약 8GB)가 가장 쉽다. [F2]
- **Gemma 3**는 1B/4B/12B/27B 라인업. 4B 이상은 **이미지 입력 + 128K 컨텍스트 + 140개 언어**. [F3]
- **더 세게**: Qwen 3 235B(추론·코딩), DeepSeek R1(수학), Llama 4 Scout(최대 10M 토큰 롱컨텍스트) — 단, 이건 큰 VRAM/다중 GPU 필요. [F1]

## 어떻게 돌리나 — 도구 2개

- **Ollama** — 사실상 표준. 명령어 한 줄로 모델 받고 실행, **OpenAI 호환 API** 자동 제공. 양자화·GPU 배분 알아서. [F4]
- **LM Studio** — 클릭으로 쓰는 비주얼 버전. Hugging Face 원클릭 다운로드, 로컬 서버(포트 1234). [F4]

## 그래서 나는?

민감 데이터를 다루거나, API 비용이 상시로 나가거나, 오프라인이 필요하면 **로컬이 답일 수 있다.** 반대로 가끔 쓰는 정도면 굳이 필요 없다.

## 지켜볼 것 (솔직히)

위 모델들의 **한국어 품질**은 아직 실측 데이터로 확인 못 했다. [G] 다음 편에서 Ollama로 Gemma 3를 우리 표준 시나리오에 물려 **토큰 속도·한국어 품질을 직접 재서** 숫자로 보고할 계획이다.

> 💬 **[경험 삽입]** 당신 GPU로 실제 돌려본 모델과 체감 속도 한 줄 — 이게 이 글의 핵심 자산이다.
