# 파인콘, AI 에이전트용 지식 엔진 'Nexus' 공개 프리뷰로 전환

# 세 줄 요약

- 벡터 데이터베이스(문장의 뜻을 숫자 좌표로 바꿔 저장하는 데이터베이스) 회사 Pinecone(파인콘)이 AI 에이전트용 지식 엔진 Nexus(넥서스)를 2026년 5월 5일 처음 공개한 뒤, 7월 1일 공개 프리뷰로 전환했어요.
- 파인콘 발표에 따르면 토큰 비용을 최대 90% 줄이고, 작업 완료 시간을 30배 단축하고, 완료율 90% 이상을 기록했다고 해요.
- 이 수치들은 파인콘이 자체적으로 측정해 발표한 값이에요. 이번에 모은 자료에서 제3자가 독립적으로 확인한 결과는 찾지 못했어요.

---

# 1. 회사 문서를 AI가 찾아준다는 도구

어느 회사든 직원이 "작년 2분기 판매 자료 어디 있어?"라고 물으면, 보통은 사람이 폴더 여러 개를 뒤져야 해요.

[Pinecone(파인콘)은 이 과정을 AI로 처리하겠다며 지식 엔진 Nexus(넥서스)를 만들었어요](https://pinecone.io/nexus-preview/). 아래는 지금까지의 진행 단계예요.

| 시점 | 내용 |
|---|---|
| 2026년 5월 5일 | 초기 공개 |
| 2026년 7월 1일 | 공개 프리뷰로 전환 |
| 현재 | 신청한 기업 고객이 미리 써보는 단계 (정식 출시 전) |

문장이나 문서의 '뜻'을 숫자 좌표로 바꿔 저장해서 AI가 의미로 검색하게 해주는 데이터베이스를 벡터 데이터베이스(Vector Database)라고 해요. 파인콘은 원래 이 벡터 데이터베이스를 만드는 회사이고, 이번엔 그 기술을 활용해 회사 문서를 AI 에이전트가 찾아 쓸 수 있게 하는 도구를 내놓았어요.

이 발표에 담긴 성능 수치가 어떻게 측정된 것인지는 4번에서 자세히 짚어볼게요.

---

# 2. Nexus는 어떤 기술로 작동하나요?

[Nexus는 Context Compiler(컨텍스트 컴파일러)와 KnowQL(노우QL)이라는 두 기술로 작동해요](https://pinecone.io/blog/nexus-features/).

| 기술 | 하는 일 |
|---|---|
| Context Compiler | 긴 문서 더미를 읽고 핵심만 뽑아 정리해요 |
| KnowQL | 정리된 내용을 AI 에이전트가 검색하기 쉬운 질의어로 바꿔요(파인콘이 만든 전용 언어) |

비유하면 이래요. 회사 문서 창고에 상자 수천 개가 쌓여 있어요. Context Compiler는 상자마다 겉면에 내용물 요약표를 붙이는 일이고, KnowQL은 그 요약표를 어떤 말로 검색하면 원하는 상자가 나오는지 정해주는 규칙이에요. = 사람이 상자를 직접 열어보지 않아도, AI 에이전트가 요약표와 검색 규칙만으로 필요한 상자를 찾아낸다는 뜻이에요.

---

# 3. 숫자로 보는 성능 (파인콘 발표 기준)

| 항목 | 파인콘 발표 수치 |
|---|---|
| 토큰 비용 절감 | 최대 90% |
| 작업 완료 시간 단축 | 30배 |
| 작업 완료율 | 90% 이상 |
| 새 요금제 | Builder tier, 월 20달러 |
| 클라우드 통합 | Microsoft OneLake 연동 |

AI가 글을 세는 단위를 토큰(Token)이라고 하는데, 이 개수만큼 비용이 매겨져요. 다만 "작업 완료율 90%"가 정확히 어떤 작업 몇 건을 기준으로 잰 수치인지는, 이번에 모은 자료에 구체적으로 나와 있지 않아요.

---

# 4. 이 수치는 어디서 측정됐나요?

표에 있는 수치는 모두 [파인콘의 자체 성능 보고서 페이지](https://pinecone.io/blog/nexus-performance/) 하나에서 나온 것이에요.

| 확인 여부 | 내용 |
|---|---|
| 파인콘 자체 발표 | 토큰 절감률·속도 개선·완료율 전부 |
| 제3자 언급 | [TechCrunch](https://techcrunch.com/2026/07/pinecone-nexus/), [InfoQ](https://infoq.com/articles/pinecone-nexus-2026/)가 Nexus를 다룬 기록이 있으나, 두 매체가 수치를 독자적으로 재검증했는지는 확인되지 않음 |
| 사용자 실측 시도 | [Reddit(레딧) r/database](https://reddit.com/r/database/pinecone-nexus-benchmarks/)에서 댓글 1,000개 이상으로 논의가 이어졌지만, 결론이 난 결과는 확인되지 않음 |

정리하면, 토큰 90% 절감·30배 빠름이라는 수치는 현재 파인콘 쪽 발표이고, 다른 곳에서 실제로 써본 결과가 나와야 비교할 수 있는 단계예요.

---

# 5. 요금과 통합 — Builder tier, OneLake

[파인콘은 이번에 월 20달러짜리 Builder tier(빌더 티어) 요금제를 새로 만들었어요](https://pinecone.io/pricing/). 개인 개발자나 소규모 팀이 낮은 비용으로 먼저 써볼 수 있는 구성이에요.

또 [Microsoft의 클라우드 데이터 플랫폼 OneLake(원레이크)와 연동을 지원한다고 밝혔어요](https://pinecone.io/blog/nexus-integrations/). OneLake에 데이터를 이미 쌓아둔 기업이라면 Nexus를 그 위에 이어서 쓸 수 있다는 뜻이에요.

# 7. 앞으로 지켜볼 것

앞으로 지켜볼 것 세 가지예요.

- 파인콘 밖의 회사나 개발자가 직접 써보고 발표하는 독립적인 성능 결과가 나오는지
- Nexus가 공개 프리뷰를 지나 정식 출시(GA)로 넘어가는지, 그때 조건이 어떻게 바뀌는지
- Weaviate·Milvus 같은 경쟁 벡터DB들이 비슷한 기능을 내놓는지

이 답들이 나오면, 이번 발표에 나온 수치가 실제 사용 환경에서도 유지되는지 좀 더 분명해질 거예요.
