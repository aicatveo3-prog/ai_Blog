# Claude Sonnet 5, "에이전트 싸게 굴리세요" — 근데 '반값'은 반만 믿어요

> **유형** · A 속보 브리핑 · 쉽고 재밌게 읽는 버전  **상태** · ✅ 발행 (v3)
> **관점** · 성능 뉴스가 아니라 "에이전트를 상시 돌리는 비용의 손익분기점"이 내려간 사건. 단, 가격표 밑 작은 글씨(토크나이저)를 조심하자.

---

> **하나만 짚고 갈게요.** 여기 나오는 성능 점수·가격은 대부분 앤트로픽이 "우리가 이만큼"이라고 발표했거나 리뷰 매체가 정리한 값이에요. 그대로 믿기보다 링크를 눌러 직접 확인하는 걸 추천해요.

# 세 줄 요약

- 앤트로픽이 최고 모델(Opus)에 **거의 근접한 성능**의 **Claude Sonnet 5**를 절반 수준 가격에 내놨어요.
- 진짜 뉴스는 성능이 아니라 **"AI 에이전트를 늘 켜두는 비용"이 싸졌다**는 거예요.
- 근데 가격표 밑에 함정이 있어요 — **토큰 세는 방식이 바뀌어서** '반값'이 반값이 아닐 수 있어요.

---

# 1. 무슨 일이 있었냐면요

앤트로픽이 **"이제 AI 에이전트를 싸게 굴리세요"**라며 새 모델을 반값 수준에 내놨어요. 성능도 자기네 최고 모델에 거의 근접하고요.

근데 가격표 밑에 **작은 글씨**가 하나 숨어 있어요. 그거 때문에 '반값'이 반값이 아닐 수 있어요. (이 얘긴 5번에서 회수할게요.)

무슨 일인지 하나씩 볼게요. [2026년 6월 30일, 앤트로픽이 **Claude Sonnet 5**를 공개했어요](https://www.anthropic.com/news/claude-sonnet-5). 한 줄로 요약하면 이래요 — **최고급에 가까운 성능을, 중간 등급 가격에.**

여기서 잠깐, 용어 하나. 사람이 일일이 시키지 않아도 **스스로 여러 단계를 처리하는 AI**를 **에이전트**라고 불러요. "코드 고쳐줘" 하면 알아서 파일 열고, 고치고, 확인까지 하는 식이죠.

# 2. 그래서 뭐가 싸졌는데요?

먼저 요금 얘길 하려면 용어 하나가 필요해요. AI는 글을 통째로 읽지 않고 **잘게 쪼갠 조각**으로 처리해요. 이 조각을 **토큰**이라고 하고, 요금은 글자 수가 아니라 **이 토큰 개수로** 매겨져요.

- **입력 토큰** = 내가 AI에게 넣는 글 (질문·자료)
- **출력 토큰** = AI가 뱉는 답

Sonnet 5 가격은 이래요.

| 항목 | 내용 |
|---|---|
| 출시일 | [2026년 6월 30일](https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents/) |
| 도입가 (~8/31) | 입력 **$2** / 출력 **$10** (100만 토큰당) |
| 이후 정가 | 입력 **$3** / 출력 **$15** |
| 어디서 | [무료·프로 플랜의 **기본 모델**](https://www.anthropic.com/news/claude-sonnet-5), 전 플랜 제공 |

가볍게 쓰는 분은 이미 Sonnet 5를 쓰고 있는 거예요 — 무료·프로 기본이 이걸로 바뀌었거든요.

한 가지만 기억하세요. **8월 31일**이 도입가($2/$10)가 끝나는 날이에요. 그 뒤엔 입력 $3 · 출력 $15가 정가라, 장기 비용은 이 숫자로 잡아야 해요.

# 3. 성능은요? — "최고는 아닌데 거의 최고"

AI 실력을 재는 시험을 **벤치마크**라고 해요. 그중 '코드를 스스로 짜고 고치는' 에이전트 시험 결과가 이래요.

| 모델 | 점수 |
|---|---|
| Opus 4.8 (최상급) | 약 69% |
| **Sonnet 5** | **약 63%대** |
| Sonnet 4.6 (직전 세대) | 약 58% |

*(수치는 [MarkTechPost의 비교 정리](https://www.marktechpost.com/2026/06/30/anthropic-claude-sonnet-5-vs-sonnet-4-6-vs-opus-4-8-agentic-coding-benchmarks-api-pricing-and-cost-performance-tradeoffs-compared/) 기준. 시험 이름이 매체마다 조금씩 달라서 "약 63%대"로 완충해 적었어요.)*

= 쉽게 말해 Sonnet 5는 "1등"이 아니라 **"거의 1등인데 훨씬 싼"** 쪽이에요. 심지어 대학원 수준 추론 시험 하나에선 [Sonnet 5가 Opus를 근소하게 앞섰다](https://www.buildfastwithai.com/blogs/claude-sonnet-5-review-benchmarks-pricing-2026)는 리뷰도 있어요.

# 4. 진짜 뉴스는 '성능'이 아니라 '비용'이에요

자동화를 돌리는 입장에선 여기가 핵심이에요. 에이전트는 일 하나를 하려고 AI를 **수십~수백 번** 불러요.

비유하면, 심부름 하나 하는데 택시를 100번 갈아타는 셈이에요. 그래서 택시비(모델값)가 조금만 싸져도 **전체 심부름 비용이 확** 달라져요.

= 그동안 "최고 모델(Opus)은 상시 돌리기엔 비싸서" 미뤄둔 자동화가 있었다면, 그 **손익분기점이 이번에 내려왔어요.**

게다가 Sonnet 5는 [복잡한 작업을 중간에 멈추지 않고 끝까지 하고, 시키지 않아도 자기 답을 점검한다](https://www.anthropic.com/news/claude-sonnet-5)고 해요. 에이전트에선 "끝까지 하느냐"가 곧 비용이라(중간에 멈추면 사람이 다시 시켜야 하니까), 이 변화의 체감이 클 수 있어요.

# 5. 근데 잠깐 — '반값'은 반만 믿어요

**근데 잠깐, 여기서 함정이 있어요.**

Sonnet 5는 **토큰을 세는 방식(토크나이저)이 바뀌었어요.** 그래서 [똑같은 글이 예전보다 약 1.0~1.35배 더 많은 토큰으로 계산돼요](https://llm-stats.com/llm-updates).

기억하죠? 요금은 토큰 개수로 매겨진다고 했잖아요. 그러니 이런 일이 생겨요.

| 가격표만 보면 (표시가) | 실제 청구서 |
|---|---|
| "입력 100만 토큰당 $2!" | 같은 글이 토큰 1.0~1.35배로 계산됨 |
| "정가도 $3, 예전보다 싸다" | 토큰이 늘면 표시가만큼 안 싸짐 |
| "반값에 에이전트 상시 구동" | 내 워크로드에 따라 최대 35%까지 어긋남 |

= 가격표엔 "한 조각에 얼마"라고 적혀 있는데, 조각을 **더 잘게 써는 칼**로 바뀐 거예요. 조각당 값은 싸졌어도 조각 수가 늘면 총액은 생각만큼 안 줄어요.

그러니 정확히는 반값이 아니라 **"반값에 가까움, 단 내 워크로드에 따라"**예요. "입력 $2!"만 보고 예산을 짜면 어긋날 수 있어요.

# 6. 그래서 나는 뭘 해야 하나요?

- **에이전트·자동화를 돌리는 분** → 비용 때문에 접었던 자동화를 다시 계산해볼 때예요. 단, 표시가 말고 **내 실제 입출력으로 토큰을 재본 뒤** 판단하세요.
- **가볍게 쓰는 분** → 무료·프로 기본이 이미 Sonnet 5예요. 딱히 할 건 없고, 답이 더 끈질겨진 걸 체감하면 돼요.
- **모두** → **8월 31일** 이후엔 정가($3/$15)라는 것만 기억해두세요.

# 결론

Sonnet 5는 "성능이 세졌다"보다 **"에이전트를 늘 켜두는 비용이 싸졌다"**가 진짜 뉴스예요. 잘 나온 모델인 건 맞고, 동시에 '반값'이라는 표현엔 토크나이저라는 별표가 붙어요 — 둘 다 사실이에요.

앞으로 지켜볼 것 세 가지:

- **한국어에선 토크나이저가 토큰을 얼마나 더 먹을까?** 이건 아직 공개 데이터로 확인 못 했어요(솔직히 몰라요). 한국어는 영어보다 토큰이 더 붙는 편이라 특히 중요해요.
- **벤치마크 수치가 공식 모델카드로 확정되면** "약 63%대"가 정확히 몇 점인지 갱신할게요.
- **경쟁이 어디까지 갈까?** [TechCrunch도 "에이전트를 더 싸게 돌리는 길"로 이 소식을 짚었어요](https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents/) — '싸게 상시 구동' 경쟁은 이제 시작이에요.
