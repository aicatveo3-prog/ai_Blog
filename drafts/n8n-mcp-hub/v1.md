# n8n 2.0? 진짜 뉴스는 버전 번호가 아니라 'MCP 허브'가 된 것

> **유형** · A 속보 브리핑  **상태** · 검수중(P5 사람 편집 대기)
> **관점** · 2.0은 보안·성능 릴리즈일 뿐. 진짜 변화는 그 전 몇 달간의 MCP 양방향 지원 — n8n이 에이전트 도구 허브가 됐다.

**한 줄 요약** — "n8n 2.0 나왔다, AI 대변신!"이라는 말이 돌지만, **2.0 자체는 보안·성능 릴리즈**다. 정작 중요한 변화는 그 앞에서 조용히 일어났다 — n8n이 **MCP를 양방향으로** 지원하며 도구 허브가 된 것.

---

## 무슨 일이 있었나

먼저 오해부터 정리. **n8n 2.0은 AI 기능 릴리즈가 아니다.** Code 노드 기본 샌드박스화, Publish/Save 패러다임 등 **보안·신뢰성·성능** 릴리즈다. [F1]

진짜 뉴스는 버전 번호 뒤에 있다. n8n은 최근 몇 달간 **MCP(Model Context Protocol)**를 양쪽으로 다 지원하기 시작했다. [F3]

| 무엇 | 내용 |
|---|---|
| 도구로 소비 (2026-05-19) | 노드 패널에서 MCP 서버를 **골라서 클릭**하면 에이전트 도구로 붙음. 수동 설정 불필요. 초기: Apify·Linear·monday·Notion·PostHog [F2] |
| 서버로 노출 | 내 워크플로를 **MCP 서버로** 열어 외부 AI가 호출 [F3] |
| 인스턴스 MCP (2026-04) | Claude Desktop·ChatGPT·Cursor가 n8n 안에서 워크플로 build/test/publish [F4] |

---

## 그래서 나는 뭘 해야 하나

- **자동화를 짜는 사람** → 그동안 API 연결마다 손으로 붙이던 걸, 이제 **MCP 서버 클릭 몇 번**으로 끝낼 수 있다. 조립 비용이 확 준다.
- **Claude·ChatGPT를 쓰는 사람** → n8n 워크플로를 **채팅창에서 직접** 만들고 돌릴 수 있다 (인스턴스 MCP). [F4]
- **버전 번호에 낚이지 말 것** → "2.0=AI"가 아니다. 실제 AI 변화는 MCP 지원 쪽을 봐야 한다.

## 지켜볼 것

초기 MCP 커버리지가 5개 서비스라, **국내 서비스(카카오·네이버 등) 커넥터가 언제 들어오는지**는 아직 확인 못 했다. [G] 다음 편에서 n8n MCP로 우리 표준 시나리오(정보 파이프라인)를 **직접 구축해 실측**할 계획이다.

> 💬 **[경험 삽입]** n8n MCP를 실제로 한 번 붙여보고, 예전 수동 연결 대비 체감 한 줄.
