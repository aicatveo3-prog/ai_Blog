# OpenAI를 떠난 CTO가 만든 첫 모델, 누구나 쓸 수 있어요

# 세 줄 요약

- OpenAI의 전 CTO Mira Murati(미라 무라티)가 세운 Thinking Machines Lab이 첫 모델 Inkling(잉클링)을 공개했어요.
- 975억 파라미터 규모인데, 질문 하나에 41억 개만 깨워서 실행 비용을 크게 줄였어요.
- 개방가중(open-weight) 모델이라 누구나 다운로드해서 직접 돌릴 수 있어요.

---

# 1. OpenAI에서 가장 중요한 사람이 왜 나갔을까

2026년 7월 16일, [Thinking Machines Lab이 Inkling을 공개](https://techcrunch.com/2026/07/16/thinking-machines-lab-inkling/)했어요. 이 회사의 CEO가 Mira Murati(미라 무라티)예요. GPT-4 출시 당시 OpenAI의 CTO(최고기술책임자)였고, ChatGPT를 세상에 내놓는 데 핵심 역할을 한 사람이에요.

그 사람이 OpenAI를 떠나서 만든 첫 모델이 — 폐쇄형이 아니라 개방형이에요.

= OpenAI의 "닫힌 AI" 노선과 정반대를 택한 거예요. GPT-5.6은 API로만 쓸 수 있고 가중치를 공개하지 않는데, Inkling은 다운로드해서 자기 서버에서 마음대로 돌릴 수 있어요.

왜 이 방향을 택했는지에 대한 Murati의 공식 설명은 아직 확인되지 않았어요. 하지만 결과물 자체가 하나의 선언이에요 — "AI 모델은 특정 회사에 갇혀 있을 필요가 없다"는.

---

# 2. 975억인데 41억만 깨운다고요?

[Inkling은 총 975억 개의 파라미터](https://techcrunch.com/2026/07/16/thinking-machines-lab-inkling/)를 갖고 있어요. 파라미터는 AI가 학습한 내용을 저장하는 단위예요. 많을수록 더 복잡한 걸 이해할 수 있어요.

그런데 질문이 들어올 때마다 975억 개를 전부 쓰지 않아요. [쿼리당 41억 개만 활성화](https://techcrunch.com/2026/07/16/thinking-machines-lab-inkling/)돼요.

이런 구조를 필요한 부분만 깨워 쓰는 방식이라고 하고, 기술 용어로는 **MoE**(Mixture of Experts, 혼합 전문가)라고 불러요. 최근 나온 대형 모델들(Moonshot AI의 Kimi K3, Meituan의 LongCat 등)이 대부분 이 구조를 쓰고 있어요.

| 구분 | 총 파라미터 | 활성 파라미터 | 비고 |
|---|---|---|---|
| Inkling | 975억 | 41억 | 개방가중 |
| Kimi K3 | 2.8조 | 미공개 | 개방가중 |
| GPT-5.6 Sol | 미공개 | 미공개 | 폐쇄형 |

결과적으로 실행에 필요한 컴퓨팅 자원이 줄어들어요. Thinking Machines Lab은 "Frontier 모델보다 훨씬 저렴한 실행비"라고 주장하는데, 구체적인 가격 비교나 독립 벤치마크는 아직 나오지 않았어요.

---

# 3. "개방가중"이 독자에게 의미하는 것

개방가중 모델은 가중치 파일을 누구나 다운로드할 수 있어요. 자기 컴퓨터나 클라우드 서버에서 직접 돌릴 수 있다는 뜻이에요. API 호출 비용을 안 내도 되고, 데이터가 외부 서버로 나가지 않아요.

반대로 폐쇄형 모델(GPT-5.6, Claude 등)은 회사 API를 통해서만 쓸 수 있어요. 가격을 그 회사가 정하고, 질문과 답변이 회사 서버를 거쳐요.

개방가중 모델이 주는 변화:

- **스타트업·연구자**: 고성능 모델을 API 비용 없이 자체 인프라에서 실행할 수 있어요
- **기업**: 민감한 데이터를 외부에 보내지 않고 AI를 쓸 수 있어요
- **경쟁 구도**: 폐쇄형 모델만 쓸 수 있었던 작업을 개방형으로도 할 수 있게 되면, API 가격 경쟁이 생겨요

다만 "Frontier급 성능"이라는 Thinking Machines Lab의 주장은 아직 독립적으로 검증되지 않았어요. 공개 벤치마크 결과나 제3자 평가가 나와야 확인할 수 있어요.

---

# 4. 아직 확인 안 된 것들

솔직히, 이 모델에 대해 확인된 정보보다 안 된 정보가 더 많아요.

**확인된 것:**
- 975억 파라미터, 쿼리당 41억 활성화
- 개방가중 모델
- Mira Murati가 CEO인 Thinking Machines Lab이 개발
- 2026년 7월 16일 공개

**확인 안 된 것:**
- 구체적인 벤치마크 점수 (다른 모델과 성능 비교)
- 학습 데이터의 출처와 규모
- 라이선스 세부 조건 (상업적 사용 가능 여부)
- 실행에 필요한 최소 하드웨어 사양
- 경쟁사(OpenAI·Google·Meta 등)의 공식 반응

출시 직후라 업계 반응도 아직 모이지 않았어요. 한국 언론 보도도 확인되지 않았어요. 시간이 지나면서 독립 평가와 커뮤니티 반응이 나올 거예요.

---

# 5. 앞으로 지켜볼 것

- **독립 벤치마크**: MMLU, HumanEval 등 표준 테스트에서 Inkling이 어느 수준인지가 나와야 "Frontier급"이라는 주장을 검증할 수 있어요.
- **커뮤니티 수용**: 개발자들이 실제로 다운로드해서 써보고 나면 — 속도, 품질, 메모리 사용량에 대한 실측 데이터가 나와요.
- **Murati의 다음 행보**: 첫 모델 공개 이후 투자 유치, 팀 확장, 후속 모델 계획이 어떻게 나오는지가 이 회사의 방향을 보여줄 거예요.
