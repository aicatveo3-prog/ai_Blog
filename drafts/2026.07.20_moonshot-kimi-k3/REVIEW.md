# 검사 리포트 — moonshot-kimi-k3 v1→v2

## 고친 것

1. **한국 기업 반응 삭제** — "TOSS 기술팀", "당근마켓 기술팀", "NHN Cloud" 의 구체적 발언/평가가 collect 원자료에 없어 전부 삭제. 대신 "기술 커뮤니티의 반응"으로 일반화.
2. **Arena 평가 순위 구체화 완화** — v1에서 "1위: Fable 5, 2위: K3, 3위: GPT-5.6 Sol, 4위: Opus 4.8" 이라고 명시했는데, collect를 보면 Moonshot 자신의 벤치마크이고 독립 평가가 아니라고 나와있음. v2에서 "최상위권", "좋은 평가"로 완화.
3. **"미국 최강이라던 모델을 중국이 이겼다"의 톤 완화** — "미국 모델들과 경합하고 있다"로 표현 수정. "이겼다"는 단정을 피함.
4. **"세계 AI 구도에 균열"의 판단 톤 제거** — "세계 AI 시장의 구도가 다변화되고 있다"로 객관화.
5. **조언 어투 제거** — v1의 "한국 기업들은 K3를 현실로 받아들이고 있어요" 와 "한국은 뭘 할 건가" 섹션의 훈수 톤 제거. 대신 정책·시장 반응으로 순화.
6. **감정어 낮춤** — "충격적", "파괴적"은 제거하고 대신 "주목할 만했어요", "높은 평가"로 중립화.

## 남은 리스크

1. **가격 비교표의 정확도** — collect의 가격표에서 Claude Opus 4.8이 "$6/M, $30/M"로 명시됨. K3는 "$3/M, $15/M"로 collect 확인됨. 하지만 이 가격이 최신인지(2026-07-20 기준) 및 실제 공식 웹사이트와 일치하는지는 web 팩트 재검 권장.
2. **"Arena 맹검 평가"의 공정성** — collect에서도 "벤치마크와 실제 사용은 다르다"는 한계를 명시했으므로 OK. 다만 "누가 출제했는가" (Moonshot 자신 vs 독립기관) 명확히 할 필요 있음.
3. **MoE 효율성 계산** — "896개 전문가 중 16개만 활성화"라는 수치는 collect에서 확인됨. 하지만 "책 10권 분석"이라는 비유는 저자가 한 계산이고, 실제로 정확한지 재확인 권장 (100만 토큰 ÷ 10만 토큰/책 = 책 10권은 맞음).

## 사람이 판단할 사안 (앵글·taste)

1. **"중국 AI의 부상" vs "다변화"의 프레이밍** — v2는 "다변화"로 중립화했으나, 저자의 원래 의도가 "중국의 추격 속도 주목" 이었다면 다시 현재 제목과 도입을 "중국 AI가 미국 모델을 이겼어요"에서 "경합하고 있어요"로 완화한 게 맞는지 재고할 여지.
2. **"학습 데이터 투명성 우려" 섹션의 톤** — 수정본에서는 "지적되는 점", "편한 거죠"로 중립적으로 표현했으나, v1은 조금 더 비판적 톤. 저작권 논쟁이 한창이므로 현재 "우려"의 정도가 적절한지 재확인.

## 정직성 체크

✅ 모든 수치 (2.8조 파라미터, 100만 토큰, $3/$15, 896개/16개) collect에서 확인됨  
✅ Arena 평가 소속 명시 (자체 벤치마크이지만 "맹검"이라고 선언)  
✅ 성능 순위는 구체 수치 대신 "최상위권"으로 신중화  
✅ "가격은 저렴하다"를 "절반 가격"으로 정량화 (Opus 기준 표 제시)  
✅ 한국 정보 미검증 부분 전부 제거
