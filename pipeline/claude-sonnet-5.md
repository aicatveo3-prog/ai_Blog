**보류 사유 (②)**: 점수는 근소차. 우리 색깔엔 더 맞지만(직접 테스트 최적), 신선도가 살짝 지났고 첫 글로는 "직접 돌려보기"가 필요해 준비 시간이 큼 → **다음 편(직접 테스트) 후보로 이월**.

**탈락 사유 (③)**: 아직 '프리뷰'라 직접 검증이 불가 → 킬 기준 "내가 직접 안 써본 도구의 사용기"에 인접. 실체가 나오면 재검토.

## 3. 관점 (분석)

기준: `system/analysis-frameworks.md`

**적용한 프레임워크**
- **So-What 3단**: 가격 인하(1단) → 미뤄둔 자동화의 손익분기점 하락(2단) → "에이전트 상시 구동"이 일반화되는 구조 변화(3단)
- **반대 가설**: "반값이라더니 진짜 반값 맞나?" → **토크나이저 변경(1.0~1.35배)**으로 표시가만큼 안 싸짐 = 남들이 안 짚는 차별화 지점
- **로컬 번역**: 한국어에서 토큰 증가율은 미확인 → 글에 "모른다"고 정직하게, 다음 편 직접 테스트 예고

**확정한 관점 한 문장**
> Claude Sonnet 5는 성능 뉴스가 아니라 "에이전트를 상시 돌리는 비용의 손익분기점"이 내려간 사건이다. 단, 새 토크나이저 때문에 '표시가 반값'을 곧이곧대로 믿으면 안 된다.

→ 이후 초안(4~5단계)은 이 관점을 축으로 작성. 조사 팩트는 `research/2026-07-04-claude-sonnet-5.md` 참고.
