# 글 유형 템플릿 4종

> P2(아웃라인) 프롬프트에 "글 유형 + 해당 구조"로 넣는다.
> 트랙 운영은 [`../workflow.md`](../workflow.md) 참조.

---

## A. 속보 브리핑
- **분량**: 600~1,000자
- **구조**: 무슨 일 → 왜 중요 → 누가 뭘 해야 → 지켜볼 것
- **역할**: 신선도·트래픽
- **주기**: 주 2~3회 / 제작 30~45분 / 자동화 ~70%

## B. 심층 분석
- **분량**: 2,500~4,000자
- **구조**: 훅(관점 제시) → 배경 → 팩트 정리 → 분석(5프레임워크 중 2~3개) → 반론 → 실전 함의 → 전망
- **역할**: 브랜드·구독 전환
- **주기**: 주 1회 / 제작 4~8h / 자동화 ~30%

## C. 직접 테스트·튜토리얼
- **분량**: 3,000자+
- **구조**: 목표 → 준비물 → 단계별(스크린샷) → 막힌 지점과 해결 → 실측 비용·시간 → 대안 비교 → 결론
- **역할**: 검색 유입 자산 (이 블로그의 핵심 해자)
- **주기**: 월 1~2회 / 제작 6~10h / 자동화 ~40%
- 반드시 `test-protocol.md`의 표준 시나리오 + 실측 로그 사용.

## D. 주간 종합
- **분량**: 1,500자 내외
- **구조**: 이번 주 한 문장 → 톱3 심층 코멘트 → 짧은 소식 5~8개 → 다음 주 관전 포인트
- **역할**: 뉴스레터·재방문
- 프롬프트: [`../prompts/G-weekly-digest.md`](../prompts/G-weekly-digest.md)
