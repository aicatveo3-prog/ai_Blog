# 일일 수집·검증 자동화 플레이북 (1단계 자동화)

> 매일 1회, "그날 새로 나온 AI 소식"을 수집 → 날짜 검증 → 인박스에 추가하는 표준 루틴.
> 이 문서가 곧 자동화의 명세다. 사람이 돌리든 크론이 돌리든 이 순서를 따른다.
> 관련: `system/collection-dating.md`(날짜 검증 규칙), `system/scoring-rubric.md`(1차 점수), `inbox.json`(데이터).

---

## 매일 실행 순서

1. **검색 (수집)** — 여러 각도로 지난 24시간 AI 소식을 웹 검색:
   모델 출시 · 자동화/노코드 · 에이전트/프레임워크 · 정책/규제 · 연구/논문 · 자금/M&A · 논란/소송 · 하드웨어. (한 각도만 보면 놓친다)
2. **후보 추출 + 중복 제거** — 제목·URL을 `inbox.json` 기존 항목과 대조해 이미 있는 건 버림.
3. **날짜 검증** (`collection-dating.md`) — 각 후보의 **1차 원문**을 찾아 게시일 확인, 2곳+ 교차.
   - 확정 → `firstSeen` 채우고 `verified:true`
   - 못 찾음 → `firstSeen:null`, `verified:false` (지어내지 않는다)
   - 지속 흐름 → `trend:true`
4. **1차 점수(선택)** — 루브릭으로 대략 점수·태그. (선별은 여전히 사람이)
5. **세 탭 구축(고신호 항목만)** — 그날 검증된 항목 중 논쟁적·파급력 큰 것은
   **정리본·자세히·반응 3개를 각각 따로** 만든다. 소식이 여럿이면 소식당 서브에이전트 병렬.
   - **정리본·자세히** → `prompts/J-collect-explainers.md`
     (`collect/<slug>-summary.md` + `collect/<slug>.md`)
   - **반응(8각도)** → `prompts/H-reactions-multiangle.md` (`collect/reactions/<slug>.md`)
   - `inbox.json`의 `articleVersions`는 **반드시 이 순서**: `정리본 → 자세히 → 💬 반응`.
   세 탭은 **선택 단계** — 조용한 날/반응 없는 소식엔 건너뛴다. 최소한 정리본만이라도 남긴다.
6. **종합 심층 글(사람 지시 시만)** — 사람이 "이 항목으로 글 써줘"라고 고른 항목에 한해
   `prompts/I-synthesis-deepdive.md`로 세 탭(정리본·자세히·반응)을 합쳐 `drafts/<slug>/v1.md` 생성.
   톤·구조 기준은 `system/writing-guide.md`, 골드 스탠다드(실물 예시)는 `drafts/microsoft-mai/v1.md`. **선별·지시 없이는 자동 생성 금지.**
7. **인박스 반영** — `inbox.json`에 append, `generated` 날짜 갱신.
8. **커밋·푸시** — `git commit` 후 designated 브랜치로 push. 대시보드는 raw 경로라 몇 초 내 반영.
9. **요약 알림(선택)** — 그날 검증된 고신호 항목 3~5개를 한 줄씩.

## 경계 (자동/사람)
- **자동**: 수집·중복제거·날짜 검증·인박스 적재 (반복 노동)
- **사람 유지**: 무엇을 글로 쓸지 **선별**, 관점, 경험, 발행 승인 (70/70 규칙)
- 즉 이 자동화는 "아침에 열면 검증된 후보가 쌓여 있는 상태"까지만 만든다.

## 품질 가드
- 날짜/수치는 **1차 미확인 시 verified:false** — 오보 방지 최우선.
- 벤치마크·가격·출시일은 특히 조심(환각·과장 다발 지점).
- 각 항목에 `verifyNote`(어떻게 확인했나)와 `source`를 반드시 남긴다.
- **모든 정보는 클릭 가능해야 한다** — 3탭(정리본·자세히·**반응**)의 모든 사실·수치·인용에 그 자리 인라인 링크 `[텍스트](URL)`. **반응(H)도 예외 없이 항목마다 `[출처](URL)` 링크**로 시작한다(최근 몇몇 반응 파일에 링크가 빠졌던 문제 재발 방지).
- **하단 `# 출처` 목록엔 제목 하이퍼링크 + 실제 전체 주소(raw URL)를 둘 다** 남긴다(정리본·자세히·반응 공통, 프롬프트 J·H 철칙 0). 출처 못 찾은 정보는 쓰지 않는다.
